# Nametag Studio

**AI 에이전트와 대화하며 완성하는 나만의 인터랙티브 전자 명찰**

목걸이 줄에 착용하는 2인치 디스플레이에 내 이름, 역할, 상태 메시지를 띄우고 귀여운 애니메이션을 보여줍니다. 텍스트 설정 파일 하나만 수정하거나, Claude Code, Codex, Antigravity, Cursor 같은 AI 에이전트에게 원하는 내용을 요청해 손쉽게 커스터마이징할 수 있습니다.

임베디드 개발 경험이 전혀 없어도 괜찮습니다. 터미널에 명령어만 복사해 붙여넣을 수 있다면 누구나 쉽게 완성할 수 있습니다.

## 준비물

| 항목 | 설명 |
|---|---|
| **보드** | Waveshare ESP32-S3-Touch-LCD-2 (2.0″ 320×240 IPS) · 약 3만 원대 |
| **케이블** | USB-C **데이터 전송** 케이블 (충전 전용 케이블 사용 불가) |
| **컴퓨터** | macOS, Linux, Windows (WSL) |
| **선택 사항** | microSD 카드 (FAT32 포맷) — 나만의 사진이나 로고를 띄울 때 |
| **선택 사항** | 외장 배터리 및 넥스트랩(목걸이 줄) — 실제로 착용하고 다닐 때 |

납땜이나 브레드보드 배선 작업이 전혀 필요 없는 완제품 모듈 구성입니다.

## 5분 빠른 시작

```bash
git clone https://github.com/mommocmoc/esp32-nametag-studio.git
cd esp32-nametag-studio

./tools/setup.sh          # 개발 환경 자동 설치 (최초 1회 실행 시 다소 시간이 걸립니다)
```

`nametag/config.h` 파일을 열고 따옴표 안의 문구를 원하는 내용으로 수정합니다.

```c
#define NAMETAG_NAME     "Cowcowwow"
#define NAMETAG_ROLE     "Maker & Tinkerer"
#define NAMETAG_ORG      "Cowcowwow"
#define NAMETAG_STATUS   "OPEN TO CHAT"
```

보드를 PC에 연결하고 펌웨어를 업로드합니다.

```bash
./tools/flash.sh
```

이게 전부입니다. 수정하고, 플래시(업로드)하고, 바로 결과를 확인하세요.

## AI 코딩 에이전트 활용하기

이 저장소는 AI 코딩 에이전트와 협업하기 좋도록 최적화되어 있습니다. 저장소 내 `AGENTS.md`에 수정 가능한 범위와 보호해야 할 펌웨어 영역이 명확히 정의되어 있어, 에이전트가 문구 변경 요청에 펌웨어 렌더링 코드를 불필요하게 뜯어고치는 문제를 방지합니다.

**Claude Code**, **Codex**, **Antigravity**, **Cursor** 등으로 이 프로젝트 폴더를 열고 다음과 같이 요청해 보세요.

> 이 프로젝트의 개발 환경을 설정하고 정상적으로 컴파일되는지 확인해줘.

> 명찰 정보를 변경해줘. 이름: 박준, 직책: Product Designer, 소속: Northwind, 상태 메시지는 "타이포그래피 질문 환영"으로 해줘. 테마는 midnight으로 적용해줘.

> 내 이름 김민준을 한글로 명찰에 띄우고 싶어.

> 직책 텍스트가 화면에서 잘려 나오는데 레이아웃을 알맞게 조정해줘.

> 다음 색상 조합으로 새로운 6번째 테마를 추가해줘: #1a1a2e #16213e #0f3460 #e94560

에이전트는 `AGENTS.md`를 참고하여 `nametag/config.h`를 안전하게 수정한 뒤, `./tools/build.sh`로 컴파일 검증까지 마치고 업로드 명령어를 안내합니다. 더 많은 프롬프트 예시는 [`docs/AGENT_PROMPTS.md`](docs/AGENT_PROMPTS.md)에서 확인할 수 있습니다.

## 커스터마이징 가이드

모든 기본 설정은 **`nametag/config.h`** 파일에서 관리합니다. 줄마다 친절한 주석이 달려 있어 C/C++ 문법을 몰라도 쉽게 이해할 수 있습니다.

- **텍스트**: 이름, 직책, 소속, 상태 메시지, 상단 헤더, 스티커 태그 3개, 하단 푸터.
- **테마**: 5가지 기본 테마를 제공합니다. `NAMETAG_THEME` 설정값으로 손쉽게 변경할 수 있습니다.

| 테마 | 분위기 |
|---|---|
| `THEME_KITSCH_POP` | 버터 옐로우, 세이지, 피치. 발랄하고 산뜻한 분위기 *(기본값)* |
| `THEME_MIDNIGHT` | 네이비, 시안, 마젠타. 어두운 행사장에서 높은 시인성 |
| `THEME_MONO_INK` | 신문 인쇄 느낌의 흑백 조합에 포인트 레드. 절제된 에디토리얼 무드 |
| `THEME_CANDY` | 버블검, 민트, 라일락. 부드러운 파스텔톤 감성 |
| `THEME_TERMINAL` | 블랙 배경에 그린 형광 텍스트. 클래식 해커 콘솔 무드 |

새로운 테마를 추가하려면 `nametag/theme.h`의 기존 테마 블록을 복사해 간편하게 등록할 수 있습니다. 브랜드 컬러 HEX 값은 `python3 tools/rgb565.py "#ff7e9e"` 명령어로 RGB565 포맷으로 변환해 사용하세요.

- **애니메이션**: 3가지 효과(아바타 눈 깜빡임/윙크, 모서리 반짝임, 상태 배지 바운스)를 각각 독립적으로 켜고 끌 수 있습니다. 3가지를 모두 활성화해도 50fps로 부드럽게 작동합니다.
- **화면 밝기 및 회전**: 행사장에서 배터리를 절약하도록 밝기를 조절할 수 있으며, 넥스트랩 착용 방향에 맞춰 화면을 180도 회전할 수 있습니다.

## 한글 및 다국어 이름 표시하기

ESP32 내장 폰트는 기본적으로 ASCII(영문/숫자)만 지원합니다. 한글, 일본어, 중국어, 키릴 문자, 이모지 등은 텍스트 문자열로 직접 입력하면 렌더링되지 않고 빈 공간으로 출력됩니다.

따라서 PC의 고해상도 시스템 폰트를 사용하여 비트맵 이미지로 미리 변환한 후 화면에 띄우는 방식을 제공합니다.

```bash
pip3 install pillow
python3 tools/make_name_bitmap.py "김민준" --size 28 --preview
```

`--preview` 옵션을 주면 터미널에 아스키 아트로 렌더링 결과를 미리 보여주므로, 보드에 업로드하기 전에 모양을 바로 확인할 수 있습니다.

```
  preview (71x25):
  ..........##..........................##...##.......#######......##....
  ..........##.............###########..##...##....................##....
  ..........##............############..##...##....#############...##....
  ...
```

변환이 완료되면 `config.h`에서 `USE_NAME_BITMAP`을 `true`로 설정하고 업로드하면 됩니다.

PC에 설치된 폰트라면 다국어 문자도 모두 지원합니다 (`"こんにちは"`, `"Привет"`, `"مرحبا"`, `"ΑΛΕΞ"` 등).

## 사진이나 로고 넣기 (microSD)

FAT32 포맷의 microSD 카드를 사용하면 사진이나 로고를 출력할 수 있습니다.

```bash
pip3 install pillow
python3 tools/prepare_image.py selfie.jpg --slot avatar
```

이미지를 64×64 크기로 리사이즈하고 원형 투명 마스크를 적용해 키링 프레임에 꼭 맞게 변환해 줍니다. 변환된 파일(`assets/sd-card/` 내 파일들)을 microSD 카드의 루트 경로에 복사해 넣은 뒤, `config.h`에서 아바타 슬롯을 활성화합니다.

```c
#define IMAGE_SLOT_AVATAR   { true, "/avatar.png",  26,  46,  64,  64 }
```

총 4개의 이미지 슬롯(전체 배경, 아바타, 스티커, 미니 아이콘)을 지원하며, 투명 배경(PNG 알파 채널)을 완벽히 지원합니다.

microSD 카드를 장착하지 않아도 정상 작동합니다. 카드가 없으면 내장 그래픽 UI로 폴백되며, 푸터에 `SD: NO-CARD`로 상태가 표시됩니다.

| 명령어 | 설명 |

| `./tools/setup.sh` | 개발 환경 및 툴체인 자동 설치 (반복 실행 가능) |

| `./tools/verify.sh` | 전체 테마 빌드 검증 (렌더링 엔진 수정 시 실행) |

## 문제 해결 (Troubleshooting)

- **보드가 인식되지 않는 경우**: 대부분 케이블 문제입니다. 외형이 동일하지만 데이터 라인이 없는 '충전 전용' USB-C 케이블 대신 반드시 데이터 전송이 가능한 케이블을 사용하세요. 이후 `./tools/doctor.sh`로 상태를 확인합니다.
- **업로드(Flash)가 실패하거나 멈추는 경우**: 수동으로 부트로더 모드에 진입하세요. 보드의 **BOOT** 버튼을 누른 상태에서 **RESET** 버튼을 짧게 누르고, **BOOT** 버튼을 놓은 뒤 `./tools/flash.sh`를 다시 실행합니다.
- **텍스트가 잘리는 경우**: 고정폭 폰트 특성상 지정된 배지 너비를 넘어가면 잘려서 표시됩니다. 권장 글자 수(영문 기준 직책 ≤ 22자, 소속 ≤ 13자, 상태 ≤ 14자, 이름 ≤ 13자)에 맞게 텍스트를 줄이거나 `nametag/layout.h`에서 해당 배지 영역의 너비를 늘려주세요.
- **화면이 켜지지 않는 경우**: `./tools/monitor.sh`로 시리얼 로그를 확인하세요. `[LCD] init FAILED` 메시지가 보인다면 보드 설정이 맞지 않은 것이며, 로그가 전혀 올라오지 않는다면 케이블 또는 전원 연결을 점검하세요.
- **`INTELSHORT` 매크로 재정의 경고가 발생하는 경우**: 그래픽 및 이미지 디코더 라이브러리 간의 중복 정의로 발생하는 정상적인 메시지이며, 펌웨어 동작에는 아무런 영향이 없습니다.

더 자세한 해결 방법은 [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md)를 참고하세요.

## 프로젝트 구조

```
nametag/
  config.h        ← 사용자 맞춤 설정 (이 파일만 수정하면 됩니다)
  theme.h         ← 컬러 팔레트 정의
  layout.h        ← 화면 UI 좌표 및 크기 정의
  nametag.ino     ← 화면 렌더링 엔진
  name_bitmap.h   ← 한글/비-라틴계 이름 비트맵 (도구로 자동 생성)
tools/            ← 환경 설정, 빌드, 업로드, 진단, 비트맵 생성 스크립트
docs/             ← 하드웨어 스펙, 커스터마이징, 프롬프트 가이드 문서
assets/sd-card/   ← microSD 카드용 이미지 리소스
AGENTS.md         ← AI 코딩 에이전트용 작업 가이드라인
```

설정(`config.h`), 디자인(`theme.h`), 레이아웃(`layout.h`)이 명확히 분리되어 있습니다. 애니메이션 영역의 좌표는 레이아웃 매크로와 연동되어 있으므로 `layout.h`에서 위치를 바꾸면 잔상 제거 및 렌더링 좌표가 자동으로 함께 업데이트됩니다.
